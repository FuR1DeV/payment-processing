Асинхронный процессинг платежей

API принимает платёж и сразу отвечает 202. Дальше всё происходит в фоне: событие из outbox публикует relay, consumer спрашивает эмулятор шлюза (2-5 с, 90% одобрений) и шлёт вебхук на приёмник, который играет сервер клиента. В карточке платежа видно каждый шаг этого пути со временем от создания платежа.

Платежи страница создаёт через тот же публичный API, что и curl (Swagger). Outbox, очереди и приёмник вебхуков она читает через служебные эндпоинты /demo/api, которые выключаются вместе со страницей (DEMO_PAGE_ENABLED=false).

Ключ API

Заголовок X-API-Key для всех запросов страницы. В локальном стеке это значение API_KEY из docker-compose.yml. Хранится в этом браузере.
